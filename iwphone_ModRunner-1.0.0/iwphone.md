
iwphone模块化任务执行框架（Module Runner）

项目简介

iwphone模块化任务执行框架是一个轻量级、高可靠的Shell脚本框架，旨在解决多模块任务的并发控制、资源隔离、日志管理等问题。适用于需要按模块化执行的自动化任务场景（如嵌入式设备管理、运维脚本调度、业务功能解耦等），支持模块独立日志、互斥执行、一键停止等核心能力，确保任务执行的稳定性与可维护性。

核心功能

1. 模块化任务执行

- 
触发文件驱动：通过临时目录（
"TMP_DIR"）中的普通文件作为触发信号（如
"/tmp/login"触发
"login"模块）。
- 
动态模块发现：自动扫描触发目录下的有效模块（过滤非法字符、空文件等），支持灵活扩展。

2. 互斥执行控制

- 
模块级锁机制：每个模块独立锁文件（
"LOCK_DIR/{module}.lock"），确保同一模块同一时间仅一个实例运行，避免资源竞争。
- 
进程存活检测：锁文件关联进程PID，自动清理失效锁文件（如进程崩溃后残留的锁）。

3. 独立日志管理

- 
模块专属日志目录：日志按模块隔离存储（
"LOG_ROOT_DIR/modules/{module}/"），包含
".log"（执行日志）、
".out"（标准输出）、
".err"（标准错误）三类文件。
- 
自动创建日志目录：首次运行时自动创建缺失的日志目录，无需手动干预。

4. 一键停止与清理

- 
脚本级停止：支持通过
"Ctrl+C"或外部命令（
"stop_script.sh"）终止脚本及所有子进程。
- 
触发文件清理：支持自动清理已执行的触发文件（
"AUTO_CLEAN=1"），避免重复触发。

5. 进程控制与容错

- 
最大并行数限制：通过
"MAX_PARALLEL"参数控制同时运行的模块数量，防止资源耗尽。
- 
异常处理：模块执行失败时记录详细日志，不影响其他模块运行；切换目录失败时自动解锁并终止当前进程。

适用场景

- 
嵌入式设备管理：如物联网设备的模块化固件升级、状态监控任务。
- 
自动化运维：服务器集群的模块化巡检、日志收集、配置同步任务。
- 
业务功能解耦：大型业务系统的功能模块独立调度（如支付模块、用户模块）。
- 
多任务并发控制：需要限制资源占用（如CPU/内存）的批量任务执行。

技术栈

- 
主语言：Shell（兼容Ash/Dash，适配安卓/Linux环境）。
- 
关键特性：进程锁（
"flock"）、信号捕获（
"SIGINT/SIGTERM"）、动态目录创建（
"mkdir -p"）。
- 
日志系统：时间戳+模块名双标识，支持标准输出/错误重定向。

项目结构

├── tmp/                  # 触发文件目录（存放待执行模块的临时文件）
├── work/                 # 模块工作根目录（按模块名存放main.sh）
│   ├── login/            # 示例模块：login
│   │   └── main.sh       # 模块执行逻辑
│   └── test/             # 示例模块：test
├── logs/                 # 日志根目录（按模块隔离）
│   └── modules/
│       ├── login/
│       │   ├── login.log # 模块执行日志
│       │   ├── login.out # 标准输出
│       │   └── login.err # 标准错误
│       └── test/
├── tmp_modules.list      # 临时触发文件列表（脚本运行时生成）
├── module_runner.pid     # 脚本自身PID记录（用于外部停止）
├── main.sh      # 主脚本（用于启动以及保活和扩展功能）
├──  iwphone.sh  # 主脚本 (核心逻辑)
├──  sync.sh    #工具脚本
├──  sync_dir.sh  #工具脚本
├── ModStart.sh  #iwphone模块安装脚本
├──  stop_runner.sh   #一键停止进程
└── uninstall.sh   #简易卸载

快速上手

1. 配置与初始化

- 
修改
"module_runner.sh"顶部的配置参数（如
"TMP_DIR"、
"WORK_DIR"、
"LOG_ROOT_DIR"）。
- 
创建模块目录（如
"work/login"），并在其中编写
"main.sh"（模块执行逻辑）。

2. 触发模块执行

- 
在
"TMP_DIR"中创建触发文件（如
"touch ./tmp/login"）。
- 
运行主脚本：
"./module_runner.sh"。

3. 查看日志

- 
模块日志存储在
"logs/modules/{module}/"目录下（如
"logs/modules/login/login.log"）。

4. 停止执行

- 
手动停止：按下
"Ctrl+C"触发优雅退出。
- 
外部停止：执行
"./stop_module_runner.sh"（需提前创建该脚本，调用
"kill"命令终止脚本PID）。
